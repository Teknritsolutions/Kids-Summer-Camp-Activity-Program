# Demo boundaries and production integration

- All identities, testimonials, numbers, prices, dates, camp policies, and staff profiles are fictional editable examples. The images are AI-generated illustrations of a camp experience, not photographs of a real facility.
- Authentication is simulated. Dashboard URLs have no access control. Passwords are validated for form behavior but never stored or verified. Do not enter real credentials or private child information.
- Enrollment and payment are simulated in this browser. There is no real reservation, charge, refund, email, subscription, or message delivery.
- The profile represents one fictional family. The admin parent view shows that family; multi-account administration requires a backend.
- Camp weeks run Monday–Friday in the sample schedule. Program durations and fees use fixed half-day/full-day weekly options. Two-week pricing is two independent half-day bookings.
- PDF receipts are genuine locally generated PDF files for simulated payments. Cancelled paid records retain their receipt history. No refund processor is connected.
- Capacity is enforced within the current local store. It is not safe for concurrent users, multiple browsers, or real-time bookings. Use transactional server-side validation for production.
- Waitlisted records currently reserve capacity in this simplified demo. Adapt this policy to your actual camp workflow.
- LocalStorage data is accessible to scripts on the same origin and can be edited by the browser user. It is not secure storage.
- Contact messages and reply drafts stay local. Subscribe forms save a preference only; no email provider is contacted.
- Charts derive from the demo records. Sparse initial data intentionally produces sparse charts rather than fabricated analytics.
- Public pages include pre-rendered seed content and use JavaScript for dynamic filtering and local data. Program/article query variants update their titles and descriptions in the browser. Dedicated server-rendered detail URLs are recommended for production indexing and link previews.
- Safety guidance is not a certification, legal approval, or verified operational claim. Obtain appropriate review for real policies and services.
- No deployment has been requested. This delivery uses the existing local folder.
