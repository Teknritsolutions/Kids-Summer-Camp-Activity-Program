campora.

Make the adventure your own.

Campora is a front-end HTML template with fictional sample content. It does not process real authentication, payments, or bookings.

Run the website

From the project folder, run node scripts/serve.cjs, then open http://127.0.0.1:4173.

Explore the demo

Open the login page and select Try parent demo or Try admin demo. No password is required. Use fictional details only.
